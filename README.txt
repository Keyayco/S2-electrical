S² Electrical — standalone Vanilla website

Open index.html directly in a browser, or serve this folder with any static web server. All seven pages, styles, JavaScript, images, icons and favicon are included. No build step, framework, package installation, font download or runtime dependency is required. System Arial/Helvetica fonts are used consistently in both versions.

The enquiry form validates details and prepares a message for WhatsApp. Nothing is submitted to a server or email service. The visitor must open WhatsApp and send the message. Phone, WhatsApp and the optional Google Maps address link open external services; network access is needed for those services only.

Gallery and hero images are generated illustrations, not actual S² Electrical projects. Replace assets/distribution.jpg and assets/lighting.jpg with real project photographs and update captions/alt text when supplied. The text-based brand treatment is a proposed website treatment, not an existing official logo. No service availability, qualifications or guarantees are asserted.

To add email/server delivery later, replace the submit handler in script.js with a verified submission service and only show delivery success after confirmation.

Navigation links use local .html pages and work when opened from disk. Native HTML details elements provide keyboard-accessible FAQs. Reduced motion is respected by CSS.
